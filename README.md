# AHMAD AI — Starter 0.1

واجهة ويب تقدمية (PWA) عربية أولية قابلة للإضافة إلى الشاشة الرئيسية على Android.

## ما الذي يعمل الآن؟
- واجهة عربية RTL متجاوبة.
- محادثة تجريبية بقواعد محلية بسيطة.
- إنشاء المهام وتعليمها كمكتملة.
- تسجيل طلبات تحتاج موافقة.
- حفظ البيانات في LocalStorage على الجهاز.
- ملفات PWA للتثبيت والعمل دون اتصال بعد أول تحميل.

## ما الذي لا يعمل بعد؟
- لا يوجد اتصال فعلي بنموذج ذكاء اصطناعي.
- لا يوجد إرسال بريد أو رسائل.
- الموافقة تسجل القرار فقط ولا تنفذ عملية خارجية.
- البيانات محلية على هذا المتصفح وليست متزامنة بين الأجهزة.

## التشغيل من الهاتف مجاناً
1. أنشئ حساباً في GitHub من المتصفح.
2. أنشئ مستودعاً جديداً باسم `ahmad-ai`.
3. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
4. من Settings ثم Pages اختر النشر من الفرع `main` والمجلد `/ (root)`.
5. افتح رابط الموقع الذي يوفره GitHub Pages باستخدام Chrome على Android.
6. من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق" إذا ظهرت.

## الخطوة التالية
ربط واجهة التطبيق بخادم خلفي آمن يستدعي نموذج الذكاء الاصطناعي. لا تضع مفتاح API داخل `app.js` أو أي ملف يصل إليه المتصفح. يجب حفظه كسرّ على الخادم.

## ملاحظة الأمان
لا تستخدم النسخة الحالية لتخزين كلمات مرور أو معلومات مالية أو وثائق شخصية حساسة. امسح بيانات المتصفح قد يؤدي إلى فقدان المهام المحلية.
